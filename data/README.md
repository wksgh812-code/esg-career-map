# 사회공헌백서 대표 프로그램 데이터 (2022~2025년판)

출처: 보건복지부·한국사회복지협의회 사회공헌센터 「사회공헌백서」 2022·2023·2024·2025년판 부록
"100대 기업 / 공공기관 사회공헌 프로그램" 표를 추출·정제한 데이터입니다.

## 파일
| 파일 | 내용 |
|---|---|
| `csr_programs.csv` / `.json` | 프로그램 1건 = 1행 (총 1,417건: 기업 1,028 / 공공기관 389) |
| `organizations.csv` | 기업·기관별 요약 (기업 130곳, 공공기관 162곳) |
| `scripts/` | 추출 스크립트 (extract → extract2022 → build → aliases → normalize 순) |

## csr_programs 컬럼
| 컬럼 | 설명 |
|---|---|
| edition | 백서 발간연도 |
| base_year | 데이터 기준연도 (= edition − 1) |
| type | 기업 / 공공기관 |
| section | 원문 구분 (100대 기업, 35대 공기업, 공공기관) |
| seq, page | 원문 표 번호, PDF 페이지 |
| org | 정규화한 기업명 (매칭 키) |
| org_raw | 원문 표기 기업명 |
| program, description | 프로그램명, 내용 |
| start_year | 시작연도 (원문에 없으면 빈칸) |
| field_std / field | 통일한 사업분야 / 원문 분야 |
| target_std / target | 통일한 사업대상 / 원문 대상 |
| esg | E/S/G (2023년판만) |
| purpose | 사업목적 (2024년판만) |
| scope | 사업범위·네트워크 (2022·2023년판만) |

## 유의사항
- 연도마다 표 항목이 달라 일부 컬럼은 특정 연도에만 값이 있습니다.
- 2022년판에는 100대 기업 표만 있습니다 (공공기관 표 없음).
- 기업명 변경(대우조선해양→한화오션, 삼성엔지니어링→삼성E&A 등)은 현재 이름으로 통합했고, `organizations.csv`의 note 칸에 적었습니다.
- 화면에 게시할 때는 출처와 기준연도를 함께 표기하세요.
